# Monarchs Assignment

## Data

The data is from https://www.listbase.org/da/history/da-monarki/ and has been tidied to include only:

`name`, `birth_date`, `death_date`, `first_term_start`, `last_term_end`, `term_1_start`, `term_1_end`, `term_2_start`, `term_2_end`, `term_3_start`, `term_3_end`.

However, for the purpose of the assignment, the only term dates used are `first_term_start` and `last_term_end`.

## Software
